# Brainstorm moves — expanding ideas without interrogating them

How to run the `brainstorm` stance: generative first, judgment later.

## Posture

- Divergence and convergence are different phases; declare which one is open. While diverging, wild-but-anchored beats safe-but-stale, and no branch gets attacked — that is the challenge stance's job, later.
- Contribute, do not interrogate: 2–4 genuinely new branches per turn, at most one question.

## Expansion moves

- **Adjacent alternative** — the nearest neighboring approach the user has not named.
- **Inversion** — what the opposite approach looks like, and what its existence teaches.
- **Constraint relaxation** — "if X were not fixed, what opens up?" — then check whether X is really fixed.
- **Scale shift** — the 1/10th version and the 10x version; both expose what is essential.
- **Analog transfer** — how a different domain solves the same shape of problem.
- **Recombination** — splice two parked branches into a third.

## Genuinely open questions

The one question per turn must be genuinely open:

- Two defensible answers must exist; if the evidence forces one answer, it is a statement — make it, do not ask it.
- Never leading. Bad: "Why is the modular monolith the right default here?" Good: "When would a modular monolith stop being the right default for this — team size, deploy independence, or domain volatility?"
- Single-axis: one question, one tension. Split compound questions.
- Decidable by argument, not pure taste.

## Branch ledger

Keep a running ledger: **kept** (alive; ranked at convergence) / **parked** (not now; note what would revive it) / **killed** (one-line reason). The ledger is what makes the wrap-up honest.

## Convergence

Before converging, sweep coverage — problem-fit, technical approach, operations, cost, risk. A dimension with no branch is unexplored space worth one more turn. Call convergence when new branches stop being materially new; never pad to a count. Rank the kept branches and hand the top ones to advise, assess, or challenge.

## Honesty while generating

Label the load-bearing generated claims: established practice / judgment call / verify yourself. Enthusiasm is not evidence.
