# Platform Go Service — Scaffold & Convention Guide

Use this skill to create a new Go microservice (or add features to an existing one) that follows the A-Team platform conventions established in `go-template`.

> **Shared infrastructure** (middleware, wrapper, kafka, logger, firestore, database, redis, httpclient, crypt, hash, token, serror, codec, validator, health, config, app) lives in the **`common`** module: `gitdev.devops.krungthai.com/ktb-digital-lending/dgl-new/shareable/common`. Services **import** it — never vendor or copy.

---

## 1. When to use this skill

Trigger on any of these requests:

- "create a new Go service / microservice"
- "add a new domain / aggregate / bounded context"
- "add an HTTP endpoint / handler" (e.g. `POST /api/v1/platform/<domain>/<action>`)
- "add a Kafka consumer / event handler" (e.g. `PRODUCT_CREATED`)
- "wire a new infrastructure client" (Firestore, MySQL, Redis, S3/GCS, external API)
- "generate mocks" / "write tests with 100% coverage"
- "refactor this handler/service" — applies the Fowler workflow

Do NOT use for: frontend code, Terraform / Kubernetes provisioning, non-Go services, or pure documentation edits.

## 2. Architectural pillars (one-line summaries)

| Pillar | Rule |
|---|---|
| **Domain-Driven Design** | One package per aggregate under `app/<domain>/`. No cross-domain imports. Domain models live next to their `access/` repository. |
| **CQRS** | Write paths (commands) and read paths (queries) live in separate `handler_<action>.go` / `consumer_<action>.go` files. Aggregates collaborate via Kafka events, never direct calls. |
| **Fowler patterns** | Repository / Cache / Gateway in `access/`. Service Layer in `service_<action>.go`. Composition Root in `router/deps.go`. Tell-Don't-Ask domain models. |
| **Go idioms** | Accept interfaces, return structs. `var _ Iface = (*impl)(nil)` compile-time check. Unexported impl types. `sync.Once` config. `context.Context` first arg. `%w` error wrap. `log/slog`. |

Full detail and dependency-flow diagram: `references/architecture.md`.

## 3. File naming convention (load-bearing)

The type prefix comes **first**. Never `<action>_handler.go` or `<dep>_storage.go`.

| Prefix | Purpose | Example |
|---|---|---|
| `handler_<action>.go` | HTTP endpoint method on `*handler` | `handler_create.go` |
| `consumer_<action>.go` | Kafka event handler method on `*handler` | `consumer_create.go` |
| `service_<action>.go` | Private service helper extracted from a handler, grouped by purpose | `service_authenticate_google.go` |
| `storage_<dep>.go` | Persistence repository (Firestore, MySQL, S3/GCS) | `storage_product.go` |
| `cache_<dep>.go` | Cache repository (Redis, Memcached) | `cache_product.go` |
| `client_<dep>.go` | External API gateway | `client_google.go` |

## 4. Standard layout

```text
<root>/
├── main.go                  # Bootstrap, signal.NotifyContext, graceful shutdown
├── config/config.go         # Nested Config struct + sync.Once C() loader
├── router/
│   ├── deps.go              # Composition root — infra clients + cleanup
│   ├── router.go            # Gin engine + middleware + register<Domain>Routes
│   └── subscriber.go        # Kafka event router + register<Domain>Events + mergeRoutes
└── app/<domain>/
    ├── handler.go           # HandlerConfig + handler struct + NewHandler
    ├── handler_<action>.go  # HTTP handler (Command or Query)
    ├── consumer_<action>.go # Kafka consumer
    ├── service_<action>.go  # Private helpers grouped by purpose
    └── access/
        ├── storage_<dep>.go # interface + unexported impl + domain model (one file)
        ├── cache_<dep>.go
        ├── client_<dep>.go
        └── mocks/mocks.go   # Auto-generated by mockery
```

`access/` files **co-locate** interface + unexported impl + domain model + sentinel errors + constants in a single file. **No** separate `model.go`, `errors.go`, or `constants.go`.

## 5. Workflow — pick the path

Identify which row matches the user's request. Each row links to the reference holding the full code template and edge cases.

| Task | Steps | Reference |
|---|---|---|
| Create a new service | 1. `go mod init <module>` and add `replace` directive for `common` <br>2. Copy `main.go`, `config/`, `router/` from this template <br>3. Delete sample `app/` domains <br>4. Add your first domain (next row) | `references/scaffolding.md` |
| Add a new domain aggregate | 1. Create `app/<domain>/access/storage_<dep>.go` (interface + impl + model) <br>2. Add `app/<domain>/handler.go` (`HandlerConfig` + `handler` + `NewHandler`) <br>3. Add `handler_<action>.go` and/or `consumer_<action>.go` <br>4. Wire in `router/router.go` (`register<Domain>Routes`) and `router/subscriber.go` (`register<Domain>Events`) <br>5. Run `mockery` <br>6. Write tests for every branch (100% coverage) | `references/domain-patterns.md` |
| Add a new HTTP endpoint | 1. Add `handler_<action>.go` with `wrapper.BindJSON[T]` + `wrapper.Respond` <br>2. Wire route in matching `register<Domain>Routes` <br>3. Add table-driven test (`mockArgs` / `args` / `want` / `prepare`) | `references/domain-patterns.md`, `references/testing.md` |
| Add a new Kafka event | 1. Add `consumer_<action>.go` with signature `func(ctx context.Context, msg kafka.Message[json.RawMessage]) error` using `kafka.BindMessage` <br>2. ## 6. Output contract

Every change produced under this skill MUST satisfy:

- File paths follow the prefix convention in §3.
- Every `app/` package reaches **100% statement coverage**: every `if err != nil` branch tested, including model getter failures (e.g. `GetID()` with bad UUID).
- Mocks are generated by `mockery` per `.mockery.yaml`. Never hand-write mocks.
- Errors flowing to a response use `serror.Wrap(err).With(slog attrs...)` for observability.
- HTTP responses use `wrapper.ResponseOption[T]` with `app.Code*` / `app.Message*` constants.
- Kafka consumers use `kafka.BindMessage` (not `json.Unmarshal`) — it deserializes **and** validates.
- Logger is `log/slog`, initialised once via `logger.New` from the common module.
- Compile-time interface check on every impl: `var _ Interface = (*impl)(nil)`.

## 7. Conventions checklist (run before committing)

- [ ] One package per aggregate under `app/`. No cross-domain imports.
- [ ] `access/` files co-locate interface + impl + model + errors + constants.
- [ ] Raw SDK handles wrapped in `access/`; common-module interfaces passed direct via `HandlerConfig`.
- [ ] `var _ Interface = (*impl)(nil)` compile-time check on every impl.
- [ ] Constructor returns the interface; impl struct is unexported.
- [ ] Context propagated: `func(ctx context.Context, ...)` on every I/O method.
- [ ] Errors wrapped with `serror.Wrap(err).With(slog attrs...)`.
- [ ] HTTP handlers use `wrapper.BindJSON` + `wrapper.Respond` with `app.Code*`.
- [ ] Kafka consumers use `kafka.BindMessage`; signature `func(ctx, msg) error`.
- [ ] Event names are `UPPER_SNAKE_CASE` (e.g. `PRODUCT_CREATED`).
- [ ] Tests use `mockArgs` / `args` / `want` local types + `prepare` function (table-driven).
- [ ] Mocks built with `access_mocks.New<Interface>Mock(t)` and use `.EXPECT()` fluent API.
- [ ] No third-party loggers — only `log/slog`.
- [ ] `make precommit` passes (mod, lint, test, vuln, vet).

## 8. Constraints

- **DO NOT** vendor or copy from the `common` module — always import.
- **DO NOT** create cross-domain imports. `app/product` cannot import `app/member`. Communicate via Kafka events.
- **DO NOT** create `model.go`, `errors.go`, or `constants.go` inside `access/` — co-locate with the file that uses them.
- **DO NOT** skip tests — coverage target is 100% for `app/` packages.
- **DO NOT** pass raw SDK handles directly to domain code — always wrap in `access/`.
- **DO NOT** mix feature work with refactoring in one commit (see Fowler workflow).
- **DO NOT** use `json.Unmarshal` in Kafka consumers — `kafka.BindMessage` enforces validation tags.
- **DO NOT** introduce preemptive abstractions; keep things concrete until flexibility is required.

## 10. Troubleshooting

| Signal | Action |
|---|---|
| Generated handler ignores existing `access/` interface | Re-read `references/domain-patterns.md` §access-layer; do not bypass the wrapper. |
| Test stalls on `mock.MatchedBy` | Confirm `args.ctx` is assigned **before** calling `prepare(m, args)` inside the loop. |
| Kafka consumer accepts invalid payload | Replace `json.Unmarshal` with `kafka.BindMessage` so binding tags run. |
| `mockery` regenerates an unexpected file | Check `.mockery.yaml`: `dir: "{{.InterfaceDir}}/mocks"` and `filename: mocks.go`. |
| Coverage stuck below 100% | Add a case for each `if err != nil`; include model-getter parse errors. |
| Subscriber start fails silently | `subscriberConfigured` requires `KAFKA_BROKERS`, `KAFKA_GROUP_ID`, and `KAFKA_TOPICS` all non-empty. |
