**An API is the set of requests a program accepts, and the replies it sends back.**

1. Your app sends a request to the API, such as `GET /users/42`.
2. The API's server runs the code that reads the data, in this case from a database.
3. The server sends the reply back to your app as JSON. Your app never touches the database itself.

**For you:** read the API's docs to see which requests it accepts and what each reply contains.

**Words:**
- **JSON**: a plain text format for sending structured data, such as `{"id": 42}`.
