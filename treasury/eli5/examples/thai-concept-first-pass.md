**CTE คือ subquery ที่ตั้งชื่อไว้ใน `WITH` แล้วเรียกชื่อนั้นซ้ำได้ทั้ง query**

1. เขียน `WITH recent_orders AS (...)` ไว้บนสุด แล้วใน `SELECT` ข้างล่างใช้ชื่อ `recent_orders` แทนที่จะเขียน subquery ซ้ำ
2. มันไม่ใช่ temp table เพราะไม่ได้สร้างอะไรไว้ใน DB พอ query รันจบ ชื่อนี้ก็หายไป
3. ที่คนใช้กันเพราะอ่านง่ายกว่า subquery ซ้อนกัน แต่ละขั้นมีชื่อบอกว่าทำอะไร

**สำหรับคุณ:** subquery ใน `FROM` ของ query นี้ ย้ายไปไว้ใน `WITH recent_orders AS (...)` แล้วใน `FROM` ก็อ้าง `recent_orders` แทน

**คำศัพท์:**
- **subquery**: `SELECT` ที่ซ้อนอยู่ข้างใน query อีกตัว
- **temp table**: ตารางที่สร้างจริงใน DB แล้วอยู่ไปจนปิด session

พิมพ์ **เพิ่ม** ถ้าอยากรู้อีกชั้น หรือบอกว่าข้อไหนยังไม่เข้าใจ
