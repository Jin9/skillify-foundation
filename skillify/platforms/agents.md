## When to activate

When the user asks to create, write, refactor, review, audit, compress, split,
merge, or adapt a SKILL.md or agent skill, follow `skillify/SKILL.md`. The
canonical skill defines all eight modes (Create, Refactor, Review, Audit,
Compress, Split, Merge, Adapt), the four-stage validation gate, and the
authoritative frontmatter, anti-pattern, and security rules. Do not duplicate
those rules here.

If the host does not auto-activate by description, invoke explicitly with
`$skillify`.
